AQI-Regression-Project/

│   ├── train_models.py       # Train all regression models
│   ├── evaluate_models.py    # Compare and evaluate models
│   ├── predict.py            # Load model & predict AQI
│
├── models/                   # Saved ML models
│   ├── linear_regression.pkl

│   ├── best_model.pkl
│
├── app/                      # Streamlit frontend
│   ├── streamlit_app.py      # Main app file
│
├── requirements.txt          # Python dependencies
├── README.md                 # Project documentation
├── .gitignore                # Ignore unnecessary files (data, logs, pycache)
